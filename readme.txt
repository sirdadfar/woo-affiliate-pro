برنامهٔ کامل همکاری در فروش برای ووکامرس با پنل فارسی، پورسانت دسته‌بندی‌شده و مدیریت تسویه.

== Description ==

افزونهٔ همکاری در فروش برای فروشگاه‌های ووکامرسی که می‌خواهند فروش را از طریق نمایندگان افزایش دهند.

* لینک اختصاصی هر نماینده با کوکی قابل تنظیم
* ثبت انتساب در لحظهٔ ساخت سفارش (مقاوم در برابر پرداخت با تأخیر)
* نرخ پورسانت پیش‌فرض و اختصاصی هر دسته‌بندی
* استثنای محصول/دسته و سقف پورسانت
* پنل نماینده با شورت‌کد
* مدیریت درخواست‌های تسویه
* محاسبات مالی با عدد صحیح (بدون خطای شناور)
* سازگار با HPOS

== Installation ==

1. پوشهٔ افزونه را در `wp-content/plugins/` قرار دهید.
2. از منوی «افزونه‌ها» فعال کنید.
3. دو صفحه بسازید: یکی با شورت‌کد `[wap_dashboard]` و دیگری با `[wap_join]`.
4. از «همکاری در فروش → تنظیمات» نرخ و سایر گزینه‌ها را تنظیم کنید.

== Frequently Asked Questions ==

= آیا با HPOS کار می‌کند؟ =
بله. سازگاری با جدول سفارش‌های سفارشی اعلام شده و همهٔ دسترسی‌ها از API عمومی سفارش انجام می‌شود.

= اگر افزونه را حذف کنم داده‌ها پاک می‌شوند؟ =
خیر. داده‌های مالی به‌صورت پیش‌فرض باقی می‌مانند تا سابقهٔ پرداخت از بین نرود.

= پورسانت چه زمانی قابل برداشت می‌شود؟ =
وقتی سفارش به وضعیت «تکمیل‌شده» برسد (یا «در حال انجام»، بسته به تنظیمات).
