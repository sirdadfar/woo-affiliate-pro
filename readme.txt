برنامهٔ کامل همکاری در فروش برای ووکامرس با پنل فارسی، پورسانت دسته‌بندی‌شده، محاسبهٔ پول با عدد صحیح و مدیریت تسویه.

== Description ==

افزونهٔ همکاری در فروش برای فروشگاه‌های ووکامرسی که می‌خواهند فروش را از طریق نمایندگان افزایش دهند، بدون مدیریت دستی با صفحهٔ گسترده و پیام مستقیم.

* لینک اختصاصی هر نماینده با کوکی ۱ تا ۳۶۵ روز (پیش‌فرض ۳۰ روز)
* آخرین کلیک برنده است و کد نامعتبر جای کد معتبر را نمی‌گیرد
* ثبت انتساب در لحظهٔ ساخت سفارش (مقاوم در برابر پرداخت با تأخیر)
* نرخ پورسانت پیش‌فرض و اختصاصی هر دسته‌بندی
* استثنای محصول/دسته و سقف پورسانت هر سفارش
* چرخهٔ وضعیت پورسانت با حفظ سابقه؛ رکوردها حذف نمی‌شوند
* پنل نماینده با شورت‌کدهای `[wap_dashboard]` و `[wap_join]`
* مدیریت درخواست‌های تسویه با شمارهٔ پیگیری
* محاسبات مالی با عدد صحیح در کوچک‌ترین واحد ارز (بدون خطای شناور)
* سازگار با HPOS (جدول سفارش‌های سفارشی ووکامرس)
* محدودیت نرخ و قفل هم‌زمانی برای ثبت‌نام و درخواست تسویه
* REST API برای اپ موبایل

== Installation ==

1. پوشهٔ افزونه را در `wp-content/plugins/` قرار دهید.
2. از منوی «افزونه‌ها» فعال کنید.
3. دو صفحه بسازید: یکی با شورت‌کد `[wap_dashboard]` و دیگری با `[wap_join]`.
4. از «همکاری در فروش ← تنظیمات» نرخ، حداقل تسویه و سایر گزینه‌ها را تنظیم کنید.
5. یک سفارش آزمایشی ثبت کنید و مسیر پورسانت را بررسی کنید.

== Frequently Asked Questions ==

= آیا با HPOS کار می‌کند؟ =
بله. سازگاری با جدول سفارش‌های سفارشی اعلام شده و همهٔ دسترسی‌ها از API عمومی سفارش انجام می‌شود. این ادعا روی نصب واقعی ووکامرس آزمون خودکار نشده است؛ پیش از استفادهٔ تولیدی یک سفارش آزمایشی بزنید.

= اگر افزونه را حذف کنم داده‌ها پاک می‌شوند؟ =
خیر. داده‌های مالی به‌صورت پیش‌فرض باقی می‌مانند تا سابقهٔ پرداخت از بین نرود. کران، transientها و قفل‌های کهنه همیشه پاک می‌شوند. برای حذف جدول‌ها و تنظیمات، گزینهٔ «حذف داده‌ها هنگام حذف افزونه» را در تنظیمات فعال کنید.

= پورسانت چه زمانی قابل برداشت می‌شود؟ =
وقتی سفارش به وضعیت «تکمیل‌شده» برسد (یا «در حال انجام»، بسته به تنظیمات). پورسانت در وضعیت «در انتظار» قابل برداشت نیست.

= آیا پرداخت خودکار انجام می‌شود؟ =
خیر. تسویه دستی است. مدیر درخواست را بررسی می‌کند، شمارهٔ پیگیری را ثبت می‌کند و وضعیت را تغییر می‌دهد.

= آیا ایمیل یا اعلان ارسال می‌شود؟ =
خیر. در این نسخه هیچ ایمیل تراکنشی برای ثبت‌نام، تأیید یا تسویه ارسال نمی‌شود.

= آیا نمایندگی چندسطحی پشتیبانی می‌شود؟ =
خیر. فقط یک سطح نماینده و یک نرخ برای هر نماینده وجود دارد.

= آیا با ووکامرس ۹.۴ آزمون شده است؟ =
این عدد در هدر افزونه اعلام شده اما روی نصب واقعی ووکامرس ۹.۴ آزمون خودکار نشده است. تست‌های خودکار فقط لایهٔ دامنه و قرارداد مارک‌آپ قالب‌ها را پوشش می‌دهند.
